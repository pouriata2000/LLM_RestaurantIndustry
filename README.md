The folder named frontend, contains the associated files and can be run by the instructions mentioned in this folder. 
The files app_finetuned.py and app_finetuned1B.py load and execute the two different pretrained models used in this research. 
app_GPT.py uses GPT API instead of a pretrained model to generate responses. 
The database.json is a simple file that is used for retrieving menu items' information.
The zipped file dataset.tar.gz is the dataset used for training the Llama models.
